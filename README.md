# MDToHTMLDocs

MDToHTMLDocs is a simple Python script to turn your existing MarkDown Documentation into clean HTML Documentation.

---

# Instructions

Below are some instructions/other things worth knowing:

## Get Started

The optimal way is to plug this into your existing GitHub WorkFlows, so the Documentation HTML File can be automatically generated and uploaded as release artifact.

Here is how to get started:

1. Copy the Example Config:
```bash
cp config.example.yml config.yml
```

2. Run the Python Script:
```bash
python3 main.py
```

3. Share your generated `*.html` File.
